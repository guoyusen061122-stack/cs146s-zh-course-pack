Objective

攻击者试图提取每个智能体的工具模式。用户虽然只能直接访问编排器智能体，却可以明确指示编排器智能体把查询转发给特定的智能体。图 5 表明，攻击者利用智能体之间的通信通道，就能把同一份利用载荷投递给每一个单独的智能体。 图 5. 提取智能体工具模式。

The attacker aims to extract the tool schemas of each agent. While users have direct access only to the orchestration agent, they can explicitly instruct the orchestration agent to forward queries to specific agents. Figure 5 shows that by taking advantage of the communication channel between agents, attackers can deliver the same exploitation payload to each individual agent. Figure 5. Extract agent tool schemas.

攻击载荷解析

Attack Payload Explanation

与智能体指令提取攻击类似，表 4 中展示的每条提示词都指向一个特定的目标智能体。在 CrewAI 中，编排器把任务「委派」给同事智能体；而在 AutoGen 中，编排器把任务「转移」给同事智能体。

Similar to the agent instruction extraction attack, each of the prompts shown in Table 4 is destined for a specific target agent. In CrewAI, the orchestrator "delegates" tasks to coworker agents, while in AutoGen, the orchestrator "transfers" tasks to coworker agents.
