# OWASP Top Ten: The Leading Web Application Security Risks

# OWASP Top Ten ：最主要的 Web 应用安全风险

The most current released version is the [OWASP Top 10 2025](https://owasp.org/Top10/2025/).

当前最新发布的版本是 [OWASP Top 10 2025](https://owasp.org/Top10/2025/)。

Previous versions are available at [OWASP Top 10 2021](https://owasp.org/Top10/2021/) and [OWASP Top 10 2017 (PDF)](https://owasp.org/www-pdf-archive/OWASP_Top_10-2017_%28en%29.pdf.pdf). Older versions are available in the [GitHub repo](https://github.com/OWASP/Top10).

此前的版本可在 [OWASP Top 10 2021](https://owasp.org/Top10/2021/) 和 [OWASP Top 10 2017 （ PDF ） ](https://owasp.org/www-pdf-archive/OWASP_Top_10-2017_%28en%29.pdf.pdf) 获取。更早的版本可在 [GitHub 仓库 ](https://github.com/OWASP/Top10)中找到。

The OWASP Top 10 is a standard awareness document for developers and web application security. It represents a broad consensus about the most critical security risks to web applications.

OWASP Top 10 是一份面向开发者与 Web 应用安全领域的标准意识文档。它代表着关于 Web 应用最关键安全风险的广泛共识。

Globally recognized by developers as the first step towards more secure coding.

全球开发者公认它是迈向更安全编码的第一步。

Companies should adopt this document and start the process of ensuring that their web applications minimize these risks. Using the OWASP Top 10 is perhaps the most effective first step towards changing the software development culture within your organization into one that produces more secure code.

企业应当采用这份文档，并着手确保其 Web 应用把这些风险降到最低。采用 OWASP Top 10 ，或许是把贵组织的软件开发文化转变为产出更安全代码的文化最有效的第一步。
