### 提取智能体工具模式

#### 目标

攻击者试图提取每个智能体的工具模式。用户虽然只能直接访问编排器智能体，却可以明确指示编排器智能体把查询转发给特定的智能体。图 5 表明，攻击者利用智能体之间的通信通道，就能把同一份利用载荷投递给每一个单独的智能体。
![威胁行为者使用一个编排器智能体，它连接着另外两个分别标注为 News Agent 和 Stock Agent 的智能体。编排器智能体与另外两个智能体之间存在植入提示注入的机会。编排器智能体中有一个标注为 'Description' 的函数，其 Input 与 Output 字段为空。News Agent 和 Stock Agent 都有多个标注为 'fun1:'、'fun2:' 等的函数字段，这些字段均为空。](https://unit42.paloaltonetworks.com/wp-content/uploads/2025/04/word-image-158346-140037-5.png) 图 5. 提取智能体工具模式。

#### 攻击载荷解析

与智能体指令提取攻击类似，表 4 中展示的每条提示词都指向一个特定的目标智能体。在 CrewAI 中，编排器把任务「[委派](https://docs.crewai.com/how-to/hierarchical-process)」给同事智能体；而在 AutoGen 中，编排器把任务「[转移](https://microsoft.github.io/autogen/stable/user-guide/agentchat-user-guide/swarm.html)」给同事智能体。
