# CS146S 常见问题（fall2026）

## 本课程会使用哪些编程语言？

本课程与具体语言无关，关注的是跨不同编程语言都适用的工具与实践。不过，示例主要使用 Python、JavaScript，并在合适处使用一些系统编程语言。重点在于理解现代开发实践，而不是精通某门具体语言。

## 我需要事先了解 Claude Code 这类 AI 工具吗？

不需要事先接触过 AI 开发工具。课程会从基础讲起，逐步过渡到更高级的用法。不过，扎实的编程基础（CS111 及以上）是必需的。

## 本课程会取代传统的软件工程课程吗？

本课程是传统软件工程课程的补充，侧重于现代工具与 AI 辅助开发。它假定你已经具备软件工程基础知识，并在此基础上引入当代实践。

## 本课程需要投入多少时间？

预计每周约 10-12 小时，包括听课、作业与项目工作。课程强调动手，因此需要花时间试用新工具与新技术。

## 课程对软件或硬件有特殊要求吗？

学生需要一台能运行现代开发工具的电脑。部分云服务可能需要订阅（Claude Code 等），但课程会在可能的情况下提供访问权限或替代方案。稳定的网络连接对云工具是必需的。

## 课程内容会有多新？

课程内容力求紧跟前沿，每周更新，以反映 AI 辅助开发领域快速变化的格局。来自领先企业的嘉宾讲者会确保学生了解最新的行业实践与新兴工具。

## 我可以旁听这门课吗？

我们接受斯坦福学生与教职员工的旁听申请。你可以听全部课程，但我们无法批改你的作业，也无法为期末项目提供建议。
