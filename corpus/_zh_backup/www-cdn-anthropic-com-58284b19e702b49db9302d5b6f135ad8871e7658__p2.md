Claude Code 的主要用例
构建 JavaScript/TypeScript 仪表盘应用
尽管他们「对 JavaScript 和 Typescript 了解得
非常有限」，团队仍然用 Claude Code 为可视化 RL 模型表现与训练数据构建完整的 React 应用。他们放手让 Claude 从零编写完整应用，比如一个 5,000 行的 Typescript 应用，而自己并不需要理解这些代码。这一点很关键，因为可视化应用所需的上下文相对较少，也不要求理解整个 monorepo，从而可以快速制作用于理解训练与评测期间模型表现的工具。

创建持久化的分析工具，而不是用完即弃的笔记本
