Claude Code 用于增长营销
增长营销团队专注于搭建覆盖付费搜索、付费社交、移动应用商店、邮件营销与 SEO 的效果营销渠道。作为一个只有一人的非技术团队，他们用
Claude Code 自动化重复性的营销任务，并创建以往需要大量工程资源才能实现的智能体化工作流。
Claude Code 的主要用例
自动生成 Google Ads 创意
该团队构建了一个智能体化工作流：处理包含数百条带效果指标的现有广告的 CSV 文件，找出表现不佳、需要迭代的广告，并生成满足严格字符限制（标题 30 个字符，描述 90 个字符）的新变体。系统使用两个专门的子智能体（一个负责标题，一个负责描述），能在几分钟内生成数百条新广告，而不必在多个 campaign 中手动创建。
这让他们能够大规模地测试与迭代，而这在以前需要花费大量时间才能做到。
用于批量创意生产的 Figma 插件
他们没有为付费社交广告手动复制和编辑静态图片，而是开发了一个 Figma 插件：识别画框，并通过替换标题与描述以编程方式生成最多 100 个广告变体，把原本需要数小时复制粘贴的工作压缩到每批半秒。这带来了 10 倍的创意产出，让团队能在关键的社交渠道上测试多得多的创意变体。
用于 campaign 分析的 Meta Ads MCP 服务器
他们做了一个与 Meta Ads API 集成的 MCP 服务器，可以直接在 Claude Desktop 应用里查询 campaign 表现、花费数据与广告效果，省去了在多个平台之间来回切换做效果分析的需要，节省了宝贵时间，而这里的每一分效率提升都会转化为更好的 ROI。
带记忆系统的高级提示工程
他们实现了一个简陋的记忆系统，记录各轮广告迭代中的假设与实验，让系统在生成新变体时能把此前的测试结果拉进上下文，从而形成一个自我改进的测试框架。这让系统化的实验成为可能，而靠人工根本无法跟踪。

Claude Code 用于产品设计
产品设计团队支持 Claude Code、Claude.ai 与 Anthropic API，专长是构建 AI 产品。即使不是开发者，也能用 Claude Code 弥合设计与工程之间的传统鸿沟，直接实现自己的设计构想，而不必与工程师反复来回沟通。
Claude Code 的主要用例
前端细节打磨与状态管理改动
以往，视觉上的微调（字体、颜色、间距）需要写大量设计文档，并与工程师来回反馈多轮；现在他们直接用 Claude
Code 实现这些改动。工程师提到，他们正在做「通常不会看到设计师去做的重大状态管理改动」，从而能够达到自己设想的精确品质。
GitHub Actions 自动开单
借助 Claude Code 的 GitHub 集成，他们只需提交描述所需改动的 issue/工单，Claude 就会自动提出代码方案，无需打开 Claude Code，为他们那批长期积压的打磨任务形成了一条顺畅的缺陷修复与功能完善流程。
快速交互式原型
把设计稿图片粘进 Claude Code，他们就能生成功能完整的原型，工程师可以立即理解并在此基础上迭代；这取代了以往静态 Figma 设计稿的循环——那些设计稿需要大量解释，还要翻译成可运行的代码。
边界情况发现与系统架构理解
他们用 Claude Code 梳理错误状态、逻辑流与不同的系统状态，从而在设计阶段就识别出边界情况，而不是等到开发后期才发现，从根本上提升了初始设计的质量。
复杂的文案改动与法律合规
面对诸如清除整个代码库里
「研究预览」提示这类任务，他们用 Claude Code 找出所有出现位置、复核周边文案、与法务实时协调改动并实施更新

- ——这一过程只用了两通 30 分钟的电话，而不是一周的反复沟通
